# guitarrita-jotita---investigacion

- Guitarra 3D + Circuitos
- basado en Karplus-Strong Algorithm
- 8 botones (una octava, Do a Do)

## Materiales (modificandose)
- Amplificador PAM8403
- ESP32 DevKit (WROOM-32 o similar)
- Protoboard 
- Cables dupont / jumpers macho-macho
- Amplificador PAM8403
- Parlante 4–8 Ω (3 W)
- Condensador de acople 1–10 µF 
- Potenciómetro 10 kΩ
- Resistencia 1 kΩ
- Condensador 100 nF
- Botones pulsadores
